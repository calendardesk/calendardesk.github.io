利用規約（公開前草案）

正式な提供開始前に確定します。

1. 適用範囲

本規約は CalendarDesk Lite の利用に適用されます。

2. 利用条件

利用者は自身がアクセス権限を有する Google アカウントを使用し、関係法令および Google の利用条件を遵守してください。

3. 禁止事項

不正アクセス、第三者の認証情報の無断使用、サービスへの妨害、法令に違反する利用を禁止します。

4. 免責

通信障害や同期遅延などにより予定が正しく表示されない場合があります。重要な予定は Google カレンダー本体でも確認してください。法令で認められる範囲で、提供者は本アプリの利用による損害について責任を負わないものとします。

5. 変更・終了

プライバシーポリシー（公開前草案）

以下は現在のローカル動作を前提とした方針案です。正式公開前に実装と照合します。

1. 取得する情報

Google OAuth による認証情報、アクセス可能なカレンダーの識別情報、予定名、日時、色、場所、説明など、予定表示に必要な情報を取得する場合があります。

2. 利用目的

予定表示、検索、通知、同期および利用者が選択した関連機能の提供に限定します。Google ユーザーデータを広告配信、販売、AI モデルの学習に利用しません。

3. アクセス権限

Google Calendar API の読み取り専用スコープ（calendar.readonly）を使用します。アプリは予定を変更・削除しない設計です。

4. 保存と保護

認証トークンは Windows の資格情報ストアを使用し、予定キャッシュや設定は利用者の PC 内に保存する設計です。提供者の独自サーバーへ予定を送信しない方針です。同期時は Google のサービスと通信します。

5. 第三者提供

法令で要求される場合を除き、Google ユーザーデータを第三者に提供しない方針です。

6. データ削除・連携解除

アプリ終了後、Windows の資格情報ストアにあるアプリの認証情報と、LocalAppData 内のアプリ用データを削除できます。Google 側のアクセス権は Google アカウントの接続管理 から取り消せます。

7. Google API ポリシー

Google API から受け取る情報の利用および他のアプリへの転送は、Limited Use 要件を含む Google API Services User Data Policy に従う方針です。

8. Webサイト

本ページは独自のアクセス解析や広告を組み込んでいません。テーマ設定のみブラウザ内に保存します。ホスティング事業者による処理については当該事業者の方針をご確認ください。

9. 提供者・お問い合わせ

提供者名、連絡先、正式な適用日は公開前に掲載します。
